# lesson-experience-revamp（C4.5）

## Why

概念型節點自測體感不佳（2026-07-18 回饋）：訊息一次給太多、題目文字過多、答題只有口述一種、一個節點連續十來輪問答沒有節奏感。prompt 已調過一輪（ef3a74e）仍治標不治本——問題在互動結構，不在措辭。C5 複習 session 要動態生成補強練習，題型系統先做好 C5 可直接重用。

## What Changes

- 概念節點上課流程改為小單元制：每個考點（examPoint）一個小單元，流程為「短教學 → 3–5 題互動題 → 單元完成回饋」，全部單元完成後進入既有的蘇格拉底檢核收尾（1–2 輪），通過才亮燈。
- 新增結構化題型：選擇題、填空題、配對題、問答題（參考多鄰國）混用；讀碼/補碼題以「題幹帶程式碼」的選擇/填空呈現（真正動手寫維持在實作型節點）。題目以單元為批次由 LLM 一次生成（含正解與解析），落 session 持久化。
- 客觀題（選擇/填空/配對）server 端比對正解即時判定，答錯顯示預生成的解析——不吃 LLM 額度；問答題由 LLM 即時判定（計額度，整體呼叫數仍低於現行逐輪檢核）。
- 好閱讀的步調：一次只呈現一題，單元教學訊息輕量（150 字內），答完即時回饋。
- 對話 UI 支援題型 widget 渲染（選項按鈕、填空輸入、配對操作、問答輸入）與單元進度指示。
- 答錯的客觀題寫入 weakness_record（沿用既有格式），供 C5 複習佇列使用。
- 掌握度粒度不變：仍以節點為單位寫入 user_lesson_mastery，C5 衰減模型不受影響。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `lesson-session`: 概念節點學習循環從「純對話多輪問答」改為「小單元制 + 混合題型」——單元拆分、批次出題、客觀題判定、問答題判定、一次一題的輕量呈現、單元完成回饋的要求；蘇格拉底檢核保留但移到單元全數完成後收尾。
- `weakness-tracking`: 弱點來源新增客觀題答錯記錄。

## Impact

- **DB**：lesson_session 新增一個 jsonb 欄位存單元狀態（題目、進度、答題結果），additive migration；無新表。
- **API**：`/api/lesson/[slug]/chat` 流程改造——單元出題納入；新增作答 endpoint：客觀題比對正解不經 LLM 不計額度，問答題 LLM 判定計額度。
- **UI**：`lesson-chat.tsx` 大改——題型 widget、單元進度、完成回饋動畫（GSAP 已在依賴中）。
- **LLM**：出題以單元為批次（一單元一次呼叫，計一次額度），整體 LLM 呼叫次數較現行逐輪檢核下降。
- **LangGraph**：session graph 節點調整（單元流程接管教學/出題，檢核收尾沿用 evaluate/reteach）。
